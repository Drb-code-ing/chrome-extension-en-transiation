# 页面：主界面（Popover）

> 实现步骤索引见 `docs/layouts/../layouts/README.md` 阶段 D。
> 主界面为单列布局，正文结果使用 `md-wx` 组件渲染；每次只展示一个状态模块。

## 1. 页面职责与模块一览

主界面承载全部核心操作：一键翻译、结果动态展示、下载。页面内按状态共 4 个模块，由界面状态机决定当前展示哪个：

| 模块 | 触发条件 | 关键元素 |
|------|----------|----------|
| 顶部栏 | 常驻 | 标题、查看原文 Markdown、设置入口 |
| 初始模块 | 打开插件 / 无结果 | 当前页面提示、一键翻译按钮 |
| 翻译中模块 | 用户点击一键翻译 | 进度提示、打字机式译文 |
| 成功结果模块 | 流式完成 | 译文渲染区（md-wx）、下载按钮 |
| 失败模块 | 提取/翻译/网络失败 | 错误提示、重试按钮 |

> 说明：顶部栏常驻显示；初始/翻译中/成功/失败 四个状态模块互斥展示。

## 2. 整体骨架（ASCII 布局）

```text
┌─────────────────────────────────────────────┐
│  [顶部栏]                                    │
│  ┌─────────────────────────────────────────┐ │
│  │  (当前状态模块：初始 | 翻译中 | 成功|失败)  │ │
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

## 3. 模块 1：顶部栏（常驻）

```text
┌─────────────────────────────────────────────┐
│  网页翻译助手                          [⚙]   │
│  ─────────────────────────────────────────── │
└─────────────────────────────────────────────┘
```

**元素与行为：**

| 元素 | 类型 | 行为 |
|------|------|------|
| 应用标题 | 文本 | 显示"网页翻译助手" |
| 设置入口 `[⚙]` | 图标按钮 | 打开扩展设置页（`chrome.runtime.openOptionsPage`） |

## 4. 模块 2：初始模块

```text
┌─────────────────────────────────────────────┐
│  当前页面                                  │
│  ┌───────────────────────────────────────┐  │
│  │  页面标题或链接占位（可识别时为地址）    │  │
│  └───────────────────────────────────────┘  │
│                                            │
│        [⚡ 一键翻译当前文章]                │
│                                            │
│  · 将提取页面正文并翻译为中文               │
│  · 图片、标题、作者、链接将会保留            │
└─────────────────────────────────────────────┘
```

**元素与行为：**

| 元素 | 类型 | 行为 |
|------|------|------|
| 页面信息框 | 文本区 | 展示当前页面地址/标题；无法读取时提示"当前页面不可用" |
| 一键翻译按钮 | 主按钮 | 发起"提取 + 翻译"流程，进入翻译中模块 |

## 5. 模块 3：翻译中模块

```text
┌─────────────────────────────────────────────┐
│  正在翻译…                                  │
│  ◐ 提取页面正文 → 已生成译文滚动展示         │
│  ─────────────────────────────────────────── │
│                                            │
│   [译文内容 · 打字机效果动态追加中]          │
│   （md-wx 渲染，随增量逐块刷新）            │
│                                            │
│  [▮▮]  ▒▒▒▒▒▒░░░░  62%                      │
└─────────────────────────────────────────────┘
```

**元素与行为：**

| 元素 | 类型 | 行为 |
|------|------|------|
| 状态文案 | 文本 | 分阶段显示"正在提取正文" / "正在翻译" |
| 译文预览区 | 打字机渲染 | 随后台增量块累积，按节奏刷新，节流避免长文卡顿 |
| 进度条（可选） | 指示区 | 粗略展示进度；无完成前不显示"已完成"文案 |

## 6. 模块 4：成功结果模块

```text
┌─────────────────────────────────────────────┐
│  翻译完成  ✓                               │
│  ┌─────────────────────────┬──────────────┐ │
│  │  [⬇ 下载译文]           │ [⬇ 下载原文] │ │
│  └─────────────────────────┴──────────────┘ │
│  ─────────────────────────────────────────── │
│                                            │
│   [翻译结果全文 · md-wx 渲染]               │
│   # 文章标题                               │
│   > **作者**: …                            │
│   > **原文链接**: …                        │
│   [翻译后的正文]                            │
│                                            │
≡ 底部操作条                                   │
│  [↻ 重新翻译]          [🌐 打开原文]       │
└─────────────────────────────────────────────┘
```

**输出内容固定格式（来自需求文档 5.5）：**

```text
# [文章标题]

> **作者**: [作者名]
> **原文链接**: [原始文章URL]

[翻译后的正文]
```

**元素与行为：**

| 元素 | 类型 | 行为 |
|------|------|------|
| 下载译文 `[⬇]` | 按钮 | 将译文 Markdown 下载为 `.md` 文件 |
| 下载原文 `[⬇]` | 按钮 | 将原文 Markdown 下载为 `.md` 文件 |
| 译文渲染区 | md-wx 渲染区 | 固定格式渲染完整译文；可滚动 |
| 重新翻译 `[↻]` | 按钮 | 再次进入翻译中模块 |
| 打开原文 `[🌐]` | 按钮 | 新标签页打开原文 URL |

## 7. 模块 5：失败模块

```text
┌─────────────────────────────────────────────┐
│  ⚠ 翻译未完成                              │
│  ─────────────────────────────────────────── │
│  无法提取当前页面的主要文章内容。            │
│  （或：认证失败 / 网络错误 / 限流等具体提示） │
│                                            │
│        [↻ 重试]                            │
│                                            │
│  · 已有最近一次成功结果不会被覆盖             │
└─────────────────────────────────────────────┘
```

**元素与行为：**

| 元素 | 类型 | 行为 |
|------|------|------|
| 错误文案区 | 文本区 | 显示分类错误提示（提取 / 认证 / 限流 / 网络 / 空响应） |
| 重试按钮 `[↻]` | 按钮 | 重新发起翻译；失败不覆盖最近一次成功结果 |

## 8. 布局规则

- 单列布局，译文渲染区为主要可滚动区域，占主要高度。
- 顶部栏固定；底部操作条仅在成功模块出现。
- 各状态模块互斥渲染，保持界面信息聚焦、无冗余元素。

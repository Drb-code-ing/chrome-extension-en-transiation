# 页面：主界面（Chrome Side Panel）

> 主界面由 Manifest 的 `side_panel.default_path` 承载。点击工具栏扩展图标后在浏览器右侧打开，不使用 Action Popup。
> 页面采用全高单列布局，长内容由主体区域统一纵向滚动，Markdown 使用 `md-wx` 渲染。

## 1. 页面职责与状态模块

主界面承载当前页面识别、正文预览、翻译、结果恢复和下载操作。顶部栏常驻，其余模块由状态机互斥展示。

| 模块 | 触发条件 | 关键元素 |
|------|----------|----------|
| 顶部栏 | 常驻 | 品牌、说明文案、设置入口 |
| 初始模块 | 无最近结果 | 当前页面信息、一键翻译、正文预览入口 |
| 最近结果模块 | 存在最近一次成功结果 | 结果元信息、完整译文、翻译当前页面 |
| 原文预览模块 | 用户请求预览 | 标题、作者、URL、原文 Markdown |
| 翻译中模块 | 翻译请求进行中 | 状态提示、流式译文 |
| 成功模块 | 流式翻译完成 | 完整译文、下载、重新翻译、打开原文 |
| 失败模块 | 提取或翻译失败 | 分类错误、返回重试 |

## 2. 整体骨架

```text
┌──────────────────────────────┐  浏览器右侧 Side Panel
│ [译] 网页翻译助手        [⚙] │  固定顶部栏
├──────────────────────────────┤
│                              │
│ 当前状态模块                  │
│                              │
│ 原文或译文长内容              │  主体统一纵向滚动
│                              │
│ 状态相关操作                  │
│                              │
└──────────────────────────────┘  高度与浏览器窗口一致
```

## 3. 顶部栏

| 元素 | 行为 |
|------|------|
| 品牌标记与标题 | 显示“网页翻译助手”和“沉浸阅读 · 即时翻译” |
| 设置按钮 | 调用 `chrome.runtime.openOptionsPage()`，在独立标签页打开设置页 |

顶部栏不参与主体滚动，侧边栏滚动长译文时保持可见。

## 4. 初始与最近结果

### 初始模块

- 展示当前活动标签页的标题和 URL。
- “一键翻译当前文章”是唯一启动翻译的主操作。
- 未配置 API Key 时允许填写并保存到本地设置。
- 可预览提取后的原文 Markdown。

### 最近结果模块

- 启动时从 `chrome.storage.local` 读取 `lastResult`。
- 展示标题、作者、原文 URL、保存时间和完整译文。
- 提供“翻译当前页面”入口。
- 只有新翻译成功后才覆盖旧结果。

## 5. 原文预览模块

- 展示提取后的标题、作者、URL 和 Markdown 正文。
- 原文区域不设置固定最大高度，随侧边栏主体连续滚动。
- “返回初始状态”关闭预览，不触发翻译。

## 6. 翻译中模块

- 连接后台 Service Worker 后，通过长连接接收模型增量。
- 增量文本经过节流后更新 `md-wx`，避免长文频繁重渲染。
- 无首个增量时显示“正在建立连接…”。
- 翻译进行中使用并发锁，重复操作不会创建多个请求。

## 7. 成功模块

输出保持以下 Markdown 结构：

```text
# [文章标题]

> **作者**: [作者名]
> **原文链接**: [原始文章 URL]

[翻译后的正文]
```

| 元素 | 行为 |
|------|------|
| 下载译文 | 通过 `chrome.downloads` 下载 `标题-译文.md` |
| 下载原文 | 下载提取后的 `标题-原文.md` |
| 译文区域 | 使用 `md-wx` 展示完整译文，不设置内部固定最大高度 |
| 重新翻译 | 返回初始状态 |
| 打开原文 | 在新标签页打开原文 URL |

## 8. 失败模块

- 根据错误码区分提取失败、认证失败、限流、网络异常、空响应和未知错误。
- “返回重试”回到初始状态。
- 失败流程不调用 `saveLastResult`，最近一次成功结果保持不变。
- 翻译端口意外断开时退出加载状态并显示网络错误。

## 9. Side Panel 布局规则

- 页面使用 `width: 100%`、`height: 100vh`，不设置 Popup 式固定宽高。
- 最小内容宽度为 `320px`；实际侧边栏宽度由 Chrome 和用户拖动决定。
- 顶部栏固定，主体区域使用 `overflow-y: auto` 独立纵向滚动。
- 译文、原文预览和最近结果不设置固定最大高度，避免长文章被限制在嵌套小窗口中。
- 图片最大宽度为容器宽度，代码和长链接必须换行，禁止横向溢出。
- 侧边栏宽度大于 `460px` 时增加左右留白。
- 所有状态模块互斥展示，减少重复信息和操作冲突。

# 页面：设置页（Options）

> 实现步骤索引见 `docs/layouts/../layouts/README.md` 阶段 D 第 15 项。
> 设置页用于配置模型与展示偏好，布局简约，仅保留必要配置项。

## 1. 页面职责与模块一览

| 模块 | 关键元素 |
|------|----------|
| 模型配置模块 | 服务基地址、API Key、模型名、采样参数、保存 |
| 展示偏好模块 | 主题、跟随系统主题、视图模式 |
| 数据与关于模块 | 清空最近一次结果、关于信息 |

## 3. 模块 1：模型配置模块

```text
┌──────────────────────────────────────────────┐
│  AI 模型                                      │
│  ──────────────────────────────────────────── │
│  服务基地址                                    │
│  [ https://dashscope.aliyuncs.com/           │
│     compatible-mode/v1                    ]  │
│                                              │
│  API Key                                     │
│  [ ●●●●●●●●●●●●●●●●●●●●●●●●      ] [显示]   │
│                                              │
│  模型名                                       │
│  [ qwen-plus                         ▼ ]     │
│                                              │
│  温度                                          │
│  [ 0.0 ──────────●─────────── 1.0 ]  0.3     │
│  ──────────────────────────────────────────── │
│  [??  测试连接 ]   [✓ 保存设置]               │
└──────────────────────────────────────────────┘
```

**元素与行为：**

| 元素 | 类型 | 行为 |
|------|------|------|
| 服务基地址 | 文本框 | 默认 Qwen 兼容地址；可切换其他服务商 |
| API Key | 密码框 | 本地存储，提供显示/隐藏；密钥最小权限 |
| 模型名 | 下拉框 | 提供 qwen-turbo / qwen-plus / qwen-max，默认 qwen-plus |
| 温度 | 滑杆 | 采样参数，提供默认值 |
| 测试连接 | 按钮 | 校验密钥与地址是否可用 |
| 保存设置 | 按钮 | 保存到 `chrome.storage.local` |

## 4. 模块 2：展示偏好模块

```text
┌──────────────────────────────────────────────┐
│  展示                                          │
│  ──────────────────────────────────────────── │
│  主题          [ minimal ▼ ]                  │
│  · minimal  sakura  forest  ocean  sunset     │
│  ┌──────────────────────────────────────────┐ │
│  │ [✓] 跟随系统主题                          │ │
│  └──────────────────────────────────────────┘ │
│  默认视图模式   [ 手机 ▪ 平板 ▪ 桌面 ]        │
│  · 影响译文中长文与图片的展示宽度              │
└──────────────────────────────────────────────┘
```

**元素与行为：**

| 元素 | 类型 | 行为 |
|------|------|------|
| 主题 | 下拉框/选择 | 选择 `md-wx` 主题 |
| 跟随系统主题 | 开关 | 控制亮/暗色跟随系统 |
| 默认视图模式 | 单选组 | 手机/平板/桌面；影响译文展示 |

## 5. 模块 3：数据与关于模块

```text
┌──────────────────────────────────────────────┐
│  数据与关于                                    │
│  ──────────────────────────────────────────── │
│  最近一次结果                                  │
│  [ 🗑 清空最近一次结果 ]                        │
│                                              │
│  关于                                         │
│  Chrome 网页 AI 翻译插件 · v0.1.0             │
│  正文由 Readability 提取，翻译调用 OpenAI      │
│  兼容接口（默认 Qwen），结果由 md-wx 渲染       │
└──────────────────────────────────────────────┘
```

**元素与行为：**

| 元素 | 类型 | 行为 |
|------|------|------|
| 清空最近一次结果 | 按钮 | 清除 `lastResult`；有确认提示 |

## 6. 布局规则

- 单列纵向布局，按模块分区。
- 各模块顶部有分区标题，保持信息聚焦、无冗余元素。
- 设置保存后即时生效，供主界面翻译直接使用。

# 手动验收清单（对应 proposal.md §9）

本文档用于 T9 收尾验证，逐项手工走查并勾选。自动化测试见各 `test/verify-*.ts`。

## 9.1 页面提取

- [ ] 典型英文新闻 / 博客 / 技术文章页：能识别标题与主要正文。
- [ ] 导航、广告、推荐、评论等非正文内容不进入翻译。
- [ ] 正文图片转换为 `![alt](src)` 并保留在对应位置。
- [ ] 原文 URL 被正确记录。

## 9.2 翻译与展示

- [ ] 从当前页面一键发起翻译。
- [ ] 译文以中文为主、流式逐步显示。
- [ ] 结果格式符合规定（标题、作者、原文链接、中文正文）。
- [ ] 标题 / 列表 / 引用 / 代码块 / 图片结构翻译后仍可读。
- [ ] 关闭并重新打开插件后，上一次完成的翻译结果依然可见。

## 9.3 持久化与失败处理

- [ ] 重新打开插件可展示最近一次已完成翻译结果。
- [ ] 新翻译成功后会替换旧结果。
- [ ] 翻译失败不会覆盖最近一次成功结果。
- [ ] 无法提取正文或翻译服务出错时，界面给出明确的错误状态。
- [ ] 无历史翻译列表 / 多条结果管理功能。

## 失败场景文案走查（T9）

在失败模块分别验证提现出的标题文案：

- [ ] 提取失败（`EXTRACT_FAILED` / `EXTRACT_EMPTY`）：无法提取当前页面的主要文章内容。
- [ ] 认证失败（`AUTH_FAILED`）：翻译服务未授权。
- [ ] 限流（`RATE_LIMITED`）：请求过于频繁。
- [ ] 网络异常（`NETWORK_ERROR`）：网络连接异常。
- [ ] 空响应（`EMPTY_RESPONSE`）：模型未返回翻译内容。
- [ ] 其他未知错误（`UNKNOWN`）：翻译未完成。
- [ ] 上述每种失败均可点击「返回重试」恢复。

## 打包检查

- [ ] 图标（16 / 48 / 128）在 `dist/icons` 中齐全。
- [ ] 权限最小化：`activeTab`、`scripting`、`storage`、`downloads`。
- [ ] 隐私说明已同步（API Key 本地存储、内容仅用于翻译）。

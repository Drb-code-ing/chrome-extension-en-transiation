# 手动验收清单

本文档对应 `proposal.md` 的验收要求。自动化验证位于 `test/verify-*.ts`。

## 1. Side Panel 入口与布局

- [ ] 点击工具栏扩展图标后，在浏览器右侧打开 Side Panel，而不是 Popup。
- [ ] 侧边栏高度与浏览器窗口可用高度一致。
- [ ] 拖动调整侧边栏宽度后，标题、按钮、代码和图片没有横向溢出。
- [ ] 长内容由主区域纵向滚动，顶部栏保持可见。
- [ ] 关闭侧边栏后，再次点击扩展图标可以重新打开。
- [ ] 设置按钮在独立标签页打开 Options 页面。

## 2. 页面提取

- [ ] 典型英文新闻、博客和技术文章可以识别标题与正文。
- [ ] 导航、广告、推荐和评论等非正文内容不进入翻译。
- [ ] 正文图片转换为 `![alt](src)` 并保留在对应位置。
- [ ] 懒加载图片和相对图片地址被转换为有效绝对地址。
- [ ] 原文 URL 被正确记录。
- [ ] 受限页面和空正文页面显示明确错误。

## 3. 翻译与展示

- [ ] 在侧边栏中点击“一键翻译当前文章”后才启动翻译。
- [ ] 重复点击不会创建多个并发翻译请求。
- [ ] 译文以简体中文为主，并随模型响应持续追加。
- [ ] 标题、作者、原文链接和正文输出格式正确。
- [ ] 标题、列表、引用、代码块和图片结构翻译后仍可读。
- [ ] 长译文不受旧 Popup 固定高度限制，可连续滚动阅读。
- [ ] 翻译端口意外断开后退出加载状态，不会无限显示翻译中。

## 4. 持久化与结果操作

- [ ] 关闭并重新打开侧边栏后，最近一次成功结果仍可见。
- [ ] 新翻译成功后替换旧结果。
- [ ] 翻译失败不会覆盖最近一次成功结果。
- [ ] 下载译文生成合法文件名的 `.md` 文件。
- [ ] 下载原文生成合法文件名的 `.md` 文件。
- [ ] “打开原文”在新标签页打开正确 URL。

## 5. 设置页

- [ ] 服务地址、API Key、模型和温度可以保存并恢复。
- [ ] 测试连接成功和失败均显示明确结果。
- [ ] 主题、跟随系统主题和默认视图模式会应用到主界面。
- [ ] API Key 默认隐藏，仅在用户主动操作时显示。

## 6. 错误文案

- [ ] `EXTRACT_FAILED` / `EXTRACT_EMPTY`：无法提取当前页面的主要文章内容。
- [ ] `AUTH_FAILED`：翻译服务未授权。
- [ ] `RATE_LIMITED`：请求过于频繁。
- [ ] `NETWORK_ERROR`：网络连接异常。
- [ ] `EMPTY_RESPONSE`：模型未返回翻译内容。
- [ ] `UNKNOWN`：翻译未完成。
- [ ] 每种失败均可返回重试，且旧结果不被覆盖。

## 7. 打包与权限

- [ ] `npm run build` 成功，`dist/manifest.json` 可以被 Chrome 加载。
- [ ] `dist/icons` 包含 16、48、128 像素图标。
- [ ] Manifest 不包含 `action.default_popup`。
- [ ] Manifest 包含 `side_panel.default_path`。
- [ ] 权限与实现一致：`activeTab`、`scripting`、`storage`、`downloads`、`sidePanel`。
- [ ] Host 权限仅包含默认翻译服务 `https://dashscope.aliyuncs.com/*`。
- [ ] Background Service Worker 正确加载后台入口，而不是 Content Script 入口。
- [ ] 隐私说明已同步：API Key 本地存储，正文只发送给用户配置的翻译服务。
